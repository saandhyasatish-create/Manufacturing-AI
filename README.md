# Manufacturing Defect Detection and Predictive Maintenance Platform

## Overview

An AI-powered platform designed to help manufacturing industries identify product defects and monitor machine health.

The system combines:

- Computer Vision for manufacturing defect detection
- Machine Learning for predictive maintenance
- An integrated dashboard for monitoring and analysis

## Main Modules

### 1. Manufacturing Defect Detection
The system analyzes product images and identifies possible manufacturing defects.

### 2. Predictive Maintenance
The system analyzes machine sensor data to identify abnormal machine behavior and maintenance risks.

### 3. Analytics Dashboard
The dashboard presents defect results, machine health information, risk levels, and relevant insights in one place.

## Project Goal

To develop a cloud-based AI system that can support manufacturing quality inspection and machine maintenance through automated analysis.
